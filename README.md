# Web Collection

A collection of multiple projects that I made during learning.

🔗 **[Live Demo](https://nonopepep7-maker.github.io/Web-collection/)**

---

## My Motivation

Built as a submission for **Hack Club Macondo**. Developed on a low-spec **4GB RAM laptop**.

---

## Features

- **Wallpaper Downloader:** Download backgrounds.
- **Messup (Chat Simulator):** Dual-dashboard chat system.
- **To-Do List:** Add and remove tasks.
- **Contact Form:** Send messages straight to my inbox.
- **Top Web:** *(Active development)*.
- **World Time:** *(Active development)*.
- **Audio Player:** Integrated background music widget.
